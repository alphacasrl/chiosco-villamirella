Gestione foto del chiosco

Qui vedi ogni voce del chiosco con la foto che sta usando adesso; le voci bordate di rosso non hanno foto. Per cambiarne una: 1. scegli l'immagine dal tuo computer col pulsante della voce — 2. premi Scarica col nome giusto: ottieni il file gia' rinominato — 3. caricalo nella cartella assets/img del repository (su GitHub: apri la cartella → Add file → Upload files → trascina → Commit), confermando la sostituzione se il file esiste gia'. Dopo un minuto il chiosco usa la foto nuova. Non serve toccare il codice: il nome del file e' il legame.

Consiglio: foto orizzontali, almeno 720 pixel di larghezza. Il formato deve essere .jpg (se il tuo file e' .png o .heic va convertito prima).
